# Иллюстрации первого этапа

Пять исходных иллюстраций созданы встроенной генерацией изображений 30.09.2026 по предоставленным владельцем макетам; шестой файл — облегчённая версия триптиха. При просмотре в полном размере проверены количество голов, инструменты, отсутствие чужих логотипов и читаемость петербургских ориентиров. В сгенерированных пейзажах архитектура стилизована: подпись «вид из мастерской» была бы художественной, не фактической фиксацией конкретной точки города. Перед релизом проверить реальное кадрирование на широком и мобильном экранах и при необходимости сделать дополнительные размеры, не растягивая маленький источник на 4K.
