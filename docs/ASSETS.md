# Иллюстрации первого этапа

Исходные V1-иллюстрации созданы 30.09.2026; финальные V2-ассеты для fidelity-оверхола добавлены тем же днём. В них нет документальных фотографий работ. Исходные PNG сохраняются в локальном каталоге генераций; в проект включены только оптимизированные WebP. V1-файлы оставлены в репозитории для отката.

## Режим генерации и исходники

Иллюстрации созданы встроенным режимом `imagegen` в Codex. Финальные WebP находятся в `public/images/`; исходные PNG сохранены локально в `C:\Users\olegk\.codex\generated_images\01a0ef36-aba1-77e0-a286-1d9c48614e5c\` под именами `exec-c4a3dfa5-8e8a-463a-b88e-9b1f69e6df8e.png` (единый десктопный фон), `exec-3befd8f5-2628-4934-a0fc-725a7479569d.png` (мобильный фон), `exec-1d5aa230-deb9-4ac6-9100-f65bb648fa69.png` (замер), `exec-25a97290-e9ba-4264-81e4-465856dc6ff0.png` (укладка), `exec-2aede6a4-7a1c-4f2b-abca-989df333e748.png` (детали).

Ключевые задания генерации: единая панорама фэнтезийного Петербурга с каменной аркой, Исаакиевским собором, пергаментной центральной канвой, вывесками, ведром и жёлтой уткой; правее — один красный трёхголовый дракон в рабочем фартуке, который прижимает уровень к кафельной стене, держит сине-белую плитку и выдыхает небольшое пламя. Отдельная вертикальная сцена сохраняет тот же персонаж и оставляет сверху место для HTML-заголовка. Три прозрачных портрета показывают разные ракурсы и действия: рулетка, укладка плитки на раствор, проверка шва через лупу. Референсом композиции служили присланные пользователем макеты.
