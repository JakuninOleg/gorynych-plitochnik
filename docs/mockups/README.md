# Продолжение главной: эскиз для 2K

Откройте [интерактивный HTML-макет](./continuation-2k.html) в браузере при ширине 2560 px. Он показывает пять самостоятельных направлений для продолжения главной: работы, услуги, запил под 45°, квиз-калькулятор и отзывы. Это презентационный макет, не подключённый к Next.js или Payload CMS.

Фотографии для работ, услуг и акцентного блока скопированы из локального проекта «Свой плиточник» (`C:\Users\olegk\code\plitochnik\svoj-plitochnik\public\images`). Некоторые исходники имеют водяной знак. Перед финальным выпуском их нужно заменить на оригиналы без знака, если они доступны. Иллюстрация героя и три портрета дракона взяты из текущего репозитория «Горыныч».

Карточки отзывов содержат демонстрационный текст и подписаны как такие. В квизе работает предварительный пересчёт при выборе помещения, размера и формата плитки; его формула условная. Следующий этап после выбора направления — сверстать утверждённые блоки в главной и определить настоящую модель расчёта и контент.
