# Презентационный сайт Горыныча

Состояние: полноценный фронтенд-макет для обсуждения с клиентом. CMS, доставка заявок и реальные данные будут подключаться следующим этапом.

## Страницы

- `/` — главная.
- `/uslugi` — каталог шести услуг.
- `/uslugi/[slug]` — отдельная услуга: описание, детали, этапы, факторы стоимости, связанные работы, вопросы и форма.
- `/raboty` — каталог шести работ с фильтром.
- `/raboty/[slug]` — отдельная работа: задача, решение, галерея, мастер и связанные услуги.
- Неизвестные услуги и работы возвращают оформленную страницу 404.

Слаги и содержимое находятся в `src/lib/marketing-content.ts`. Связь работы с услугами задаётся через `serviceSlugs`. Там же лежит галерея каждого объекта. Это место для будущего адаптера Payload; сейчас используются локальные данные.

## Порядок главной

Хедер → hero → «Три головы — один мастер» → работы → калькулятор → запил 45° → услуги → Георгий → отзывы → заявка и контакты → футер.

Первый экран сохранён как сцена из независимых изображений. Ниже используется единая бумажная фактура. Замок, чертежи и керамические детали в полях не повторяются на каждом блоке. Фотографии услуг заключены в SVG-арки, подписи работ — в бумажные рамки.

## Калькулятор

SVG меняется при выборе ванной, кухни или прихожей, формата плитки, цвета, поверхности, прямой раскладки/смещения и поворота. Размеры влияют на демонстрационную площадь и ориентировочную стоимость.

- Пол: длина × ширина.
- Стены: периметр × высота − условный проём 1,8 м².
- Цена: демонстрационные 1600 ₽/м², без реальной сметы и подготовки основания.

В калькуляторе нет этапов 1–2–3–4. Все настройки находятся рядом с живой схемой. Отправка показывает состояние макета и ничего не передаёт.

## Формы и медиа

Форма принимает ввод и выбор файлов только локально. Нет API, загрузки на сервер, отправки в мессенджер или CRM. Отзывы и тексты — демонстрационное наполнение. Исходные фотографии сохранены рядом с дополнительными генерациями; лицо Георгия используется из исходного фото. Происхождение изображений описано в `ASSETS.md`.

## Адаптив и проверка

Широкий экран: центральная канва до 1664 px на главной. Внутренние страницы используют более широкую долю окна, с тем же ограничением. До 1100 px хедер превращается в меню, пейзажные поля скрываются, процесс становится вертикальным. Для телефонов до 700 px есть отдельная узкая композиция hero, для планшетов — более широкая портретная.

`node scripts/verify-marketing.mjs` проверяет страницы на 2560, 1440, 1366, 1024, 768, 430, 390 и 320 px; переход из мобильного меню; фильтр работ; изменения калькулятора; демонстрационную форму; изображения, якоря, отсутствие горизонтальной прокрутки и маршруты 404. Снимки и отчёт сохраняются в `docs/previews/site/`.

Запуск: `npm run dev`. Проверки исходников: `npm run typecheck`, `npm run lint`, сборка: `npm run build`.
